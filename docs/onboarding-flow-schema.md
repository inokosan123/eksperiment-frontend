# Anasta Onboarding Flow Schema

Working planning document for the Anasta onboarding. Source of truth for current implementation is `components/onboarding/OnboardingView.tsx`.

## Core Narrative

Main promise:

> Protect your time. Build your rhythm. Arise.

Current onboarding structure:

1. Welcome and name conversation
2. Three value slides
3. Four context questions
4. Processing
5. Choose first setup chapter
6. Chapter 1: Protect or Build
7. Checkpoint transition
8. Chapter 2: Build or Protect
9. Final checkpoint transition
10. Rise / spiritual free section
11. Final value reflection
12. Paywall

Important product rule:

Onboarding can preview or guide the app, but onboarding-specific behavior stays inside onboarding. Real Habits, Home, Journal, Scripture, tasks, persistence, and navigation should not change just because onboarding needs a mock or guided effect.
